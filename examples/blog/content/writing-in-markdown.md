Posts support everything [marked](https://marked.js.org) can render.

## Code

```js
export async function data() {
  return { posts: await getPosts() }
}
```

## Lists and emphasis

1. Write a `.md` file in `content/`
2. Give it `title`, `date`, and `description` frontmatter
3. Run `sitelo build` — the post is now a static page *and* an RSS item

> Blockquotes work too. The RSS feed at `/rss.xml` is generated by sitelo's
> `rss` config option — one item per page under `/blog`.
